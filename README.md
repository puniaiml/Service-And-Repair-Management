## 🚀 Overview

A full-stack web application to manage service requests, inventory, staff, and service providers efficiently.

---

## ✨ Features

- 📦 Item & Inventory Management  
- 🗂️ Category Management  
- 📝 Service Requests  
- 👨‍🔧 Provider Dashboard  
- 👨‍💼 Staff Management  
- 📊 Service Tracking

---

## ⚙️ Tech Stack

- Frontend: HTML, CSS, Bootstrap  
- Backend: Flask  
- Database: MySQL
